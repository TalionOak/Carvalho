# Ingredientes

- Essências de defesa
	- Descongelamento = 2 Orbe Exaltado
	- Isolamento = 2 Orbe Exaltado
	- Aterramento = 2 Orbe Exaltado
- Costelas Conservadas 
	- 3 Orbe Exaltado
- Presságio da Necromancia Destra
	- 2 Orbe Exaltado
- Orbe Exaltado maior
	- 4 Orbe Exaltado
- Pressagio da exaltação grandiosa
	- 3 Orbe Exaltado
- Pressagio da Exaltação uniforme
	- 111 Orbe Exaltado

Total 125 Orbe Exaltado ou 1,8 Orbe Divino

# Receita
1. Pegar uma base mágica com Bastante <span style="color:rgb(255, 0, 0)">Escudo de Energia aumentado em #%</span> ou <span style="color:rgb(255, 0, 0)"># de escudo de energia máximo (local)</span> junto com <span style="font-style:italic; color:rgb(255, 0, 0)">+% de resistência</span>.
2. Transformar o item Mágico em Raro.
	1. Usar uma das seguintes Essências Superiores, <span style="color:rgb(0, 176, 240)">Isolamento, Descongelamento ou Aterramento</span> para transformar o item Mágico em Raro, assim ganhando <span style="color:rgb(255, 0, 0)">+% de resistência</span>
3. Fechar os sufixos.
	- Usar uma <span style="color:rgb(0, 176, 240)">Costela</span> com um<span style="color:rgb(0, 176, 240)"> Presságio da Necromancia Destra</span> para profanar a armadura e adicionar mais um sufixo.
		- Se você veio aqui pelo passo 5, volte para ele.
		- Somente revele a profanação após o passo 4.
4. Adicionar +2 prefixo de escudo de energia.
	- Usar um <span style="color:rgb(0, 176, 240)">Orbe Exaltado</span> com <span style="color:rgb(0, 176, 240)">Presságio da Exaltação Uniforme</span> e <span style="color:rgb(0, 176, 240)">Presságio da Exaltação Grandiosa</span> para ganhar 2 linhas de <span style="color:rgb(255, 0, 0)">escudo de energia</span>.
5. Revele a profanação.
	- Você pode usar <span style="color:rgb(0, 176, 240)">Presságio dos Ecos Abissais</span> para ter mais 3 opções de escolha.
		- Se mesmo assim não cair o que você quer, use um <span style="color:rgb(0, 176, 240)">Presságio da Luz</span> com um <span style="color:rgb(0, 176, 240)">Orbe da Anulação</span> e volte para o passo 3.
