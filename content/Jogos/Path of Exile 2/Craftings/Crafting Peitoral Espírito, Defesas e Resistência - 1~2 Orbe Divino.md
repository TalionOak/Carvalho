# Receita
1. Pegar uma base mágica com Bastante <span style="color:rgb(255, 0, 0)"># de espírito</span> junto com <span style="font-style:italic; color:rgb(255, 0, 0)">+% de resistência</span>.
2. Transformar o item Mágico em Raro;
	1. Usar uma ![[Essência Grandiosa do Aprimoramento.png|20]] <span style="color:rgb(0, 176, 240)">Essência Grandiosa do Aprimoramento</span> para adicionar mais uma linha de <span style="color:rgb(255, 0, 0)">escudo de energia\defesa</span>.
3. Fechar o sufixo;
	- Usar um ![[Orbe Exaltado.png|20]]<span style="color:rgb(0, 176, 240)">Orbe Exaltado</span> com ![[Presságio da Exaltação Uniforme.png|20]]<span style="color:rgb(0, 176, 240)">Presságio da Exaltação Uniforme</span>, ![[Presságio da Exaltação Grandiosa.png|20]]<span style="color:rgb(0, 176, 240)">Presságio da Exaltação Grandiosa</span> e um ![[Presságio da Exaltação Hábil.png|20]] <span style="color:rgb(0, 176, 240)">Presságio da Exaltação Hábil</span>, para ganhar 2 linhas de <span style="color:rgb(255, 0, 0)">+% de resistências</span>.
	- <span style="color:rgb(255, 255, 0)">23.81% de chance</span> de cair <span style="color:rgb(255, 0, 0)">Resistência de Fogo</span>, <span style="color:rgb(255, 0, 0)">Gelo</span> e <span style="color:rgb(255, 0, 0)">Raio</span> se você usou uma base com <span style="color:rgb(255, 0, 0)">+% de Resistência de Caos</span>.
	- <span style="color:rgb(255, 255, 0)">28,56% de chance</span> de cair outra coisa, como <span style="color:rgb(255, 0, 0)">deflexão</span>, <span style="color:rgb(255, 0, 0)">velocidade de recarga</span> etc..
	 ![[{7BE10FF7-3B40-413E-933D-C39FBE8C6F8C}.png]]
4. Fechar o prefixo;
	- Usar uma ![[Costelas Conservadas.png|20]] <span style="color:rgb(0, 176, 240)">Costela</span> para profanar a armadura e adicionar mais um prefixo.
5. Revele a profanação.
	- Você pode usar ![[Presságio dos Ecos Abissais.png|20]] <span style="color:rgb(0, 176, 240)">Presságio dos Ecos Abissais</span> para ter mais 3 opções de escolha.
		- Se mesmo assim não cair o que você quer, use um ![[Presságio da Luz.png|20]] <span style="color:rgb(0, 176, 240)">Presságio da Luz</span> com um ![[Orbe da Anulação.png|20]] <span style="color:rgb(0, 176, 240)">Orbe da Anulação</span> e volte para o passo 4.
