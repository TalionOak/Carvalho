# Receita
1. Conseguir uma base com <span style="color:rgb(255, 0, 0)"># ao Nível de todas as Gemas Habilidades de Magias</span> e uma com <span style="color:rgb(255, 0, 0)">Dano de <span style="color:rgb(255, 255, 255)">Raio/Caos/Física/Fogo/Gelo</span> aumentado em #%</span>
	- Se não tiver uma base com sufixo livre, pode ir para o passo 2.
	1. Usar um <span style="color:rgb(0, 176, 240)">Orbe da Ampliacação Perfeito</span>, e ter a sorte de vir <span style="color:rgb(255, 0, 0)">Velocidade de Conjuração aumentada em #%</span>.
		- Se não vier ok, mas o ideal seria ela...
2. Usar uma <span style="color:rgb(0, 176, 240)">Essência Grandiosa da Feitiçaria</span> para transformar o item Mágico em Raro, assim ganhando <span style="color:rgb(255, 0, 0)">Dano mágico aumentado em #%</span>.
3. Usar uma <span style="color:rgb(0, 176, 240)">Mandíbula</span> com um<span style="color:rgb(0, 176, 240)"> Presságio da Necromancia Canhota</span> para profanar a Varinha e adicionar mais um prefixo.
	- Revele a profanação no Poço das Almas e tente pegar um Dano Mágico Alto ou algo para a sua build com um Tier alto.
	- Você pode usar <span style="color:rgb(0, 176, 240)">Presságio dos Ecos Abissais</span> para ter mais 3 opções de escolha.
4. Preenche os sufixos com <span style="color:rgb(0, 176, 240)">Orbe Exaltado</span>.
	- Você pode usar um <span style="color:rgb(0, 176, 240)">Presságio da Exaltação Grandiosa</span> para economizar Orbes Exaltados.
5. Verifique o que você conseguiu, se tiver algo bom, pode parar por aqui.
	- Se você não conseguiu <span style="color:rgb(255, 0, 0)"># ao Nível de todas as habilidades mágicas</span>, use uma <span style="color:rgb(0, 176, 240)">Essência de Feitiçaria Perfeita</span>.
	- Você também pode usar uma <span style="color:rgb(0, 176, 240)">Essência de Diligência Perfeita</span> se quiser economizar mana nas habilidades..
