# Receita
1. Pegar uma base mágica com Bastante <span style="color:rgb(255, 0, 0)">Escudo de Energia aumentado em #%</span> junto com <span style="font-style:italic; color:rgb(255, 0, 0)">#% de resistência</span>.
2. Transformar o item Mágico em Raro;
	1. Usar uma das seguintes Essências Superiores, ![[Essência de Isolamento Superior.png|20]]<span style="color:rgb(255, 0, 0)">Isolamento</span>, ![[Essência de Descongelamento Superior.png|20]] <span style="color:rgb(255, 0, 0)">Descongelamento</span>, ![[Essência de Aterramento Superior.png|20]] <span style="color:rgb(255, 0, 0)">Aterramento</span> ou da ![[Essência Grandiosa da Ruína.png|20]] <span style="color:rgb(255, 0, 0)">Ruína</span> para transformar o item Mágico em Raro, assim ganhando <span style="color:rgb(255, 0, 0)">#% de resistência</span>.
3. Fechar os sufixos;
	- Usar uma ![[Costelas Conservadas.png|20]] <span style="color:rgb(0, 176, 240)">Costela</span> com ![[Presságio da Necromancia Destra.png|20]] <span style="color:rgb(0, 176, 240)">Presságio da Necromancia Destra</span> e tentar pegar <span style="color:rgb(255, 0, 0)">+2 ao Nível de todas as Gemas de Habilidades de Lacaios</span>
		- Você pode usar ![[Presságio dos Ecos Abissais.png|20]] <span style="color:rgb(0, 176, 240)">Presságio dos Ecos Abissais</span> para ter mais 3 opções de escolha.
		- Se você não conseguiu pegar esse modificador, pode recomeçar o <span style="color:rgb(112, 48, 160)">craft</span>.
4. Adicionar +2 prefixo;
	- Usar um ![[Orbe Exaltado.png|20]] <span style="color:rgb(0, 176, 240)">Orbe Exaltado</span> com ![[Presságio da Exaltação Uniforme.png|20]]  <span style="color:rgb(0, 176, 240)">Presságio da Exaltação Uniforme</span> e ![[Presságio da Exaltação Grandiosa.png|20]] <span style="color:rgb(0, 176, 240)">Presságio da Exaltação Grandiosa</span> para tentar ganhar +2 linhas de <span style="color:rgb(255, 0, 0)">escudo de energia</span>.
