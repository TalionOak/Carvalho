# Convite de Kulemak
O Convite de Kulemak é uma chave. Se o jogador visitar o [[Poço das Almas]] com este item no inventário, uma nova opção para "Pular" no poço será disponibilizada, permitindo o acesso à Catedral Negra e ao [[Receptáculo de Kulemak]].
