# Chamado das Sombras

| Icone                            | Nome                | Item      | Efeito                             |
| -------------------------------- | ------------------- | --------- | ---------------------------------- |
| ![[Chamado das Sombras.png\|68]] | Chamado das Sombras | Fragmento | Inicia o Encontro com o [[Bodach]] |
**Chamado das Sombras** é uma chave. Cinco dessas chaves podem ser colocadas na efígie em [[Caer Tarth]] para acessar o chefe final, o [[Bodach]].

Para ganhar o Chamado das Sombras, você precisa usar a [[Cabeça do Rei]] para iniciar o [[Cabeça do Rei|Rito dos Sem Nome]], após concluir o Ritual, você deve ter 5 Chamados das Sombras.

Arraste os Chamados das Sombras do inventário para a Efigie em [[Caer Tarth]].
